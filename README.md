# Yixin Liang · The Next Chapter

中英双语个人作品集与成长工作台。纯静态应用，无第三方运行时依赖，无后端、账号或构建步骤。

## 运行

在 `/workspace/future-planning-project` 中执行：

```sh
npm start
```

需要 Python 3，使用 8000 端口。通过 HTTP 浏览器访问；不要直接双击 HTML，因为 ES 模块需要 HTTP 服务。服务进程在新云任务中需要重新启动。

## 内容与功能

- `#overview`：个人定位、精选作品、经历时间线、职业发展方向。
- `#projects`：六项案例档案，支持分类筛选与详情弹窗；按问题、方案、证据和经验组织。
- `#lab/checker`：文案长度、必需语言、图片规格检查。
- `#lab/mail`：五封虚构邮件，按透明关键词规则分类，支持优先级筛选、已处理标记及重置。
- `#lab/release`：虚构项目的依赖与就绪看板；下游勾选不会绕过未完成的前置依赖。
- `#growth`：六项成长任务、三个工作英语场景、表达提示、浏览器语音示例、一分钟计时、学习笔记和 Markdown 导出。
- 全局中英切换；支持手机导航、键盘交互和减少动态效果偏好。

成长任务和笔记使用 `localStorage`，只保留在当前浏览器，不跨设备同步。清除浏览器数据会丢失，建议导出。存储不可用时给出提示；重置进度只清除任务勾选，不删除笔记。实验室演示的操作不持久化。

## 验证

Node.js 20+：

```sh
npm test
```

覆盖码点/字节差异、空文案、emoji、语言归一、图片边界、邮件优先级以及发行前置依赖。

当前云环境已安装 Python Playwright 与 `/usr/bin/chromium`，在网站运行时可执行：

```sh
python tests/browser_smoke.py
```

该脚本验证弹窗、项目筛选、三个演示、图片成功/失败、存储与导出、计时、双语路由、五种屏幕宽度及存储拒绝降级。其他环境需另行安装 Python Playwright 并调整 Chromium 路径；应用本身不依赖它。

## 信息与演示边界

- 案例根据用户提供的简历与总结整理。内部工具未在本站进行代码审查或复测，个人贡献范围和 AI 参与方式仍需用户确认。
- 内部效率数字明确为特定场景估算，版本和测试数量为文档记录，不能视为本站验证结果。
- 检查器是独立通用演示，不代表任何平台官方规则。图片要求：PNG/JPEG/WebP，至少 800×450，不超过 5 MiB。文案按 Unicode 码点或 UTF-8 字节计数，不是视觉字素；语言标签检查不判断翻译质量。
- 邮件是模拟消息；主题包含 deadline/截止 → P0，review/审核 → P1，其他 → P2。模拟发行流程不代表真实平台规范或审核周期。
- 所有输入与图片检查均在浏览器运行，不发送给后端。未加入分析追踪、真实邮箱连接、公司代码、非公开接口/规格或后台截图。
- 发音功能仅在用户点击时调用浏览器 SpeechSynthesis；声音取决于设备，设备可能调用在线语音服务。计时不录音、不调用麦克风、不评分。
- 没有放入电话、微信、真实联系入口或未经确认的接单承诺。

## 免费发布

可使用 GitHub Pages。提交代码后，在仓库 Settings → Pages 中选择从目标分支的根目录发布。本站资源为相对路径，路由使用 hash，适用于仓库子路径，无需服务端重写。

当前只完成本地版本，未推送或公开发布。发布前需确认案例可公开性、个人介绍与联系渠道。成长区是浏览器本地练习功能，不是具有登录隔离和云同步的个人账户。

## 文件结构

- `assets/content.js`：中英文内容与项目、英语场景数据。
- `assets/app.js`：路由、界面与本机存储。
- `assets/validation.js`：通用检查规则。
- `assets/workflows.js`：模拟邮件与发行依赖规则。
- `assets/style.css`：桌面与移动端样式。
